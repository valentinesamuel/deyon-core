# Final Feature List

## Query Language
- Structured query grammar
- Nested relation traversal
- Logical operators (AND, OR, parentheses)
- Filtering operators (eq, ne, gt, gte, lt, lte, in, nin, between, like, ilike, isNull, notNull)
- Aggregation filters
- Response shaping (field selection)
- Cursor pagination
- Hybrid search (FTS + Trigram)
- Multi-column sorting
- Automatic joins
- Security whitelisting per model

## Query Capabilities
- Self-referential relationship handling
- Polymorphic relationship support
- Query complexity scoring
- Query analytics and logging
- Query caching
- Join optimization
- Grouping queries
