# Feature Categories

## Tier 1 — Core Query Engine
- Query grammar
- Query parser
- AST builder
- Filtering system
- Nested relation filtering
- Logical expressions
- Cursor pagination
- Multi-column sorting
- Response shaping
- Relationship inclusion
- Query limits (filters, joins, depth)
- Cycle protection
- Query security (whitelisting)

- Grouping queries
- Hybrid search (FTS + trigram)

- Query cost analyzer
- Query rate limiting
- Join optimization
- Query analytics
- Query logging
- Query cache

## Tier 3 — Future Enhancements
- Adaptive query planner
- Automatic index recommendations
- Materialized views
- Query precompilation
- Federated queries
